# Card network logos (optional)

Put official card-network logo files here to show them in the card number field:

    visa.svg   mastercard.svg   amex.svg   rupay.svg

If a file is missing, the field shows the network's name as text instead.

These logos are **trademarks**. Download them only from each network's official
brand/merchant pages and follow their usage rules (minimum size, clear space,
no recolouring). Card networks publish "acceptance marks" for merchants that
accept their cards. AccessPay is a demo, so check the rules before publishing.
